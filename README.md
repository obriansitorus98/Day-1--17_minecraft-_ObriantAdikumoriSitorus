# Day-1-(minecraft)_Obrisnt_Adikumori_sitorus

## Nama Lengkap
obriant adikumori Sitorus

## Deskripsi Singkat
Repository adalah direktori terpusat, baik secara lokal di komputer maupun secara cloud di platform seperti GitHub, GitLab, atau Bitbucket yang menggunakan sistem kontrol versi umumnya Git untuk mencatat setiap perubahan, penambahan, atau penghapusan berkas di dalamnya.

## Tujuan
Mencatat seluruh riwayat perubahan kode dari waktu ke waktu, Menyimpan salinan proyek di server awan (cloud), sehingga data proyek tetap aman meskipun perangkat lokal mengalami kerusakan atau kehilangan.

## Rangkuman Materi Woekshop
1. Prompt Engineering : cara menulis instruksi agar AI memberi hasil yang tepat dan relevan. Prompt yang baik memuat Role, Task, Context, dan Format.
2. Git dan GitHub : Git adalah version control system yang mencatat perubahan file secara lokal. GitHub adalah platform online untuk menyimpan repository dan berkolaborasi

## Point Penting dan Pengetahuan Baru
-Prompt yang spesifik dan punya konteks menghasilkan output AI yang lebih baik daripada prompt singkat.
-Git dan GitHub itu berbeda: Git adalah alat di komputer, GitHub adalah layanan online.
-Perintah dasar: git init, git add ., git commit -m "pesan", git push origin main, git pull origin main, dan git clone
-Staging area berfungsi memilih perubahan mana yang masuk ke commit berikutnya.
-SSH key (ed25519) membuat koneksi ke GitHub lebih aman tanpa login berulang.
-Version control memungkinkan kita melacak siapa mengubah apa dan kapan

Bagian yang paling menantang adalah setup Git dan koneksi SSH, tetapi setelah berhasil, proses commit dan push terasa jelas.
